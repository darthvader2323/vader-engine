# Vader Social video stickers

Eighteen actual moving clips encoded as silent VP9 WEBM files for Telegram. Three each are Darth Vader, Yoda, Luke Skywalker, Chewbacca and Chucky; two are Batman; one is NBA YoungBoy.

`manifest.json` preserves the original GIPHY post and creator for each clip. These are unofficial fan sticker conversions of existing published clips, not newly generated footage or endorsements. Source artwork remains with its respective rights holders.

Each file has a 512-pixel longest edge, a duration below three seconds, at most 30 frames per second, no audio, and a size below 256 KiB. `validation.json` records dimensions, duration, bytes, frame uniqueness and SHA-256. Run `python3 stickers/build.py` to validate the packaged files. Rebuild from downloaded GIF source files with `python3 stickers/build.py /path/to/source-gifs` (requires Pillow and FFmpeg).

`sticker_setup.py` creates character-specific packs owned by the verified group creator @darthvader using an existing bot. It does not create new bots, request expanded permissions, or bypass Telegram cooldowns. It appends to existing packs without deleting or replacing prior stickers, verifies that every old unique ID remains, stops on rate limits or uncertain delivery, and never prints credentials. The manifest is append-only and keeps the exact pack order; publishing uploads only its missing tail, so rerunning does not re-upload existing assets. The Vader test packs are excluded from automation because re-uploads and pack copies received new identities. No distinct Vader account is configured. Original media and the runtime history remain intact; new Vader content requires a separately checked fresh pack. Publishing sends no test messages into the group. The runtime fetches updates when its pack cache expires or on the next worker, and Batman becomes available after adding its pack name to the shared configuration.
