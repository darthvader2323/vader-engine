# Vader Social motion stickers

Eight actual moving reaction clips encoded as silent VP9 WEBM video stickers, with three different Darth Vader clips.

Source attribution is preserved in manifest.json. Validation details and checksums are in validation.json. These are unofficial fan conversions, not endorsements by the original creators.

Every file is below three seconds and 256 KiB, with a 512-pixel longest edge, no audio, and unique moving frames.
